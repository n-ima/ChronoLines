# 詳細設計: メイン画面（年表グリッド）

対応要件: US-002/003/004/006/007/008/012。前提 ADR: [0003](../adr/0003-grid-rendering.md)。
見た目の正: [../ui/screen-01-main-grid.html](../ui/screen-01-main-grid.html) ほか
モックアップ群と [../ui/design-tokens.md](../ui/design-tokens.md)（合意後は実装がこれに従う）。

## 1. 画面構成（単一ページ）

```
+--------------------------------------------------------------------------+
| ツールバー: [年表▼] [検索_____] [タグ▼] [並び順] [範囲: 開始〜終了] [1年/10年] |
|            [＋人物] [＋イベント] [入出力] [画像出力]          [保存状態 HH:mm] |
+----------+---------------------------------------------------------------+
| (角)     | 年ヘッダー行（横スクロール連動・上に固定）                          |
| 人物列   | イベントレーン（年ヘッダー直下に固定）                              |
| (左固定) | セル領域（行=人物 × 列=年。行・列とも仮想化）        [イベント/比較    |
|          |                                                    サイドパネル] |
+----------+---------------------------------------------------------------+
```

- コンポーネント: `AppShell`（エラー境界・リカバリ画面切替）> `Toolbar` / `TimelineGrid` / `SidePanel` / ダイアログ群。
- グリッドは @tanstack/react-virtual を行・列に1つずつ（ADR 0003）。
  列幅: 1年=44px・10年=72px。行高: 28px。人物列幅: 200px。オーバースキャン: 行5・列5。
- 人物列（名前・生没年併記 例「徳川家康 1543–1616」+ 右端にタグの色ドット最大4個。
  ホバーのツールチップでタグ名を表示）は左に sticky、
  年ヘッダー+イベントレーンは上に sticky（CSS position: sticky + transform 同期）。

## 2. セルの表示規則（US-002）

`cellValue`（domain-logic.md）の結果をそのまま描画する。**色 + 書式の二重チャネル**
（NFR アクセシビリティ。トークンと実測コントラスト比は design-tokens.md が正）:

| kind | 表示 | スタイル |
|---|---|---|
| blank | 空欄 | 背景 = 地の色 |
| alive | 年齢数値（生年=0） | 生存トークン（青系の帯背景 + 濃色文字） |
| virtual | `(157)` 括弧付き数値 | 仮想トークン（グレー背景 + グレー文字）。括弧が色以外の識別チャネル |

- ホバーでツールチップ「1600年 徳川家康 57歳（生存中）」/「（没後157年相当）」。
- 10の倍数の年の列に薄い縦罫線（目視のガイド）。現在年の列に強調罫線。

## 3. イベントレーン（US-003）

- 年ヘッダー直下の固定レーン（高さ2行分）。列ごとに `eventsByColumn` の先頭から
  最大2件をチップ表示（名前を省略表示）、3件以上は `+N` バッジを出す。
- チップの配色: イベントが**タグを持つ場合は先頭タグのタグ配色**（design-tokens.md）、
  タグなしは既定のアンバー（--color-chip-bg/-text）。
- チップ・バッジ・年ヘッダーのクリック → その列を「選択列」にする（4章）。
  1年に最大100件（保証範囲）でもサイドパネルの全件リスト（スクロール）で必ず到達できる
  = 「件数の要約と展開手段」の具体形。
- 個人イベントはチップに人物アイコン + サイドパネルで人物名バッジを表示（識別要件）。

## 4. 選択列とイベント・年齢比較パネル（US-004 = コアバリュー）

- 列選択時: グリッド上でその列全体を強調背景にし、右サイドパネルを開く。
- サイドパネルの内容（上から）:
  1. 見出し: 年（`formatYear`。10年ズーム時は範囲「1600〜1609」）と〔×閉じる〕。
  2. イベント一覧: その列の全イベント（スクロール可・全件）。各行 = 名前・月日・
     個人イベントなら人物名バッジ・タグの色付きピル・メモ有無アイコン。
     クリックで展開してメモ全文と〔編集〕〔削除〕。
  3. **年齢比較リスト**: 現在表示中（絞り込み反映後）の全人物の当該年の年齢を行順で列挙。
     `alive`/`virtual` はセルと同じ色・書式（例「徳川家康 57」「豊臣秀吉 (63)」）。
     行クリックでその人物の行へスクロール。
- 家康57歳・政宗33歳が同一画面で見える形 = グリッドの強調列とこのパネルの両方で成立
  （成功指標の受け入れ条件）。
- Esc または〔×〕で選択解除。

## 5. ズーム（US-007、A-004 の具体化）

- ツールバーのトグル〔1年 | 10年〕。10年列は `decadeStart`（stored年ラベルに整列した境界。
  例: 1600〜1609、前1000〜前991。西暦1〜9のみ9年バケット。定義と境界検算表は
  domain-logic.md 1章が正で、モックアップ screen-02 の見出しと一致する）。
- 10年セルの表示規則（モックアップ screen-02 で確認する集約表現）:
  - その10年間のいずれかの年で alive → 生存帯（帯背景を列いっぱいに塗る）。
    数値は**その10年の開始年の年齢**（開始年より後の生まれなら `0`）。
  - 10年間すべて没後/未来 → 仮想帯 + `(開始年の仮想年齢)`。
  - 生年を含む10年セルは左端に開始マーカー、没年を含むセルは右端に終了マーカー
    （帯の端が視認できる = 「生存期間が帯として視認できる」要件）。
- イベントレーンは10年単位に集約し件数バッジ「n件」のみ表示。クリックでパネルに
  年別グループで全件表示。
- 切り替え時のスクロール位置: 切替前の可視範囲の**中心の列の年**を記録し、
  切替後にその年を含む列が可視範囲の中心に来るようスクロールオフセットを再計算する
  （US-007 受け入れ条件を直接満たす）。

## 6. 検索・絞り込み・並び替え（US-008）

- NFR「操作応答100ms」の実測は、デバウンス等の意図的な待ち時間を除いた処理時間
  （入力確定〜描画完了）で測る（テストフェーズの計測条件）。
- 検索ボックス: 入力150msデバウンスで `searchPersons`。ヒット行の人物列を強調し、
  「k/n件」表示 + 〔前へ/次へ〕でヒット行へ順にスクロール（`scrollToIndex`）。
  ヒット0件は入力欄の下に「該当なし」を表示し、表示は変化させない（受け入れ条件）。
- タグ絞り込み: ツールバーの〔タグ▼〕ボタンでドロップダウンパネルを開き、
  `allTags`（人物・イベントのタグの和集合）を**チェックボックスで複数選択**（OR条件）。
  各候補にはタグ色ドット + 件数（人物n・イベントm）を添える。
  適用中はツールバーに選択タグを**色付きピル**（design-tokens.md のタグ配色）で表示し、
  各ピルの ✕ で個別解除、〔すべて解除〕で全解除。
  絞り込みは人物行（`filterByTags`）とイベント（`filterEventsByTags`）の両方に適用し、
  選択タグのいずれかを持つものだけを表示する（US-008 の2026-08-12差分）。
- 並び替え: トグル〔生年順 | 手動〕。手動時は人物列にドラッグハンドルを表示し、
  行のドラッグ&ドロップで `reorderPerson`（Pointer Events で自前実装。行高固定なので
  ドロップ位置 = オフセット/行高）。並び順は保存データに含まれ再起動後も復元（US-008）。
  〔生年順〕へ戻すのはワンクリック（personOrder は保持。data-model.md 4章）。

## 7. 表示範囲の指定（US-006）

- ツールバーの〔開始年〕〔終了年〕テキスト入力（`parseYearInput`。前100/-100/1600 を受理）。
  空欄 = 自動（`autoRange`）。プレースホルダに自動値を薄く表示する。
- 不正入力（形式・0年）は入力欄直下にインラインエラー、適用しない。
  開始 > 終了は「開始年は終了年以前にしてください」（E-RANGE-INVERTED）。
- 範囲内に生存期間もイベントもない場合: グリッドは空欄のまま描画し、グリッド上部に
  バナー「指定した範囲（1200〜1300）に該当する人物・イベントはありません」を表示（エラーにしない）。
- 人物0件・イベント0件の年表: 中央に空状態表示「人物を追加して年表を作りましょう〔＋人物を追加〕」。

## 8. 画像出力（US-012・Could。実装優先度は全Mustの後）

- ツールバー〔画像出力〕: 表示中のグリッド領域（人物列・年ヘッダー・イベントレーン・
  可視セル範囲）を PNG としてダウンロードする。
- 実装: `html-to-image` の `toPng` をグリッドコンテナに適用（可視範囲のみが対象。
  ADR 0003 の「画面に見えているものが正」と整合）。ファイル名
  `chronolines-<年表名>-<YYYYMMDD>.png`。
- 失敗時はトースト「画像の生成に失敗しました」のみ（機能単位に閉じ込め、他へ波及させない）。
- 印刷は専用機能を作らない（ブラウザ標準の印刷で代替。要件で確定済み）。

## 9. 状態・エラーの横断表示

- 起動時ロード中: 中央スピナー。GET 失敗（接続不可）: 全画面の接続エラー + 〔再試行〕。
- 保存エラーバナー・保存済み表示・競合ダイアログ: server-api.md 5章の仕様に従う。
- リカバリ画面（E-STORE-CORRUPT / E-STORE-NEWER）: ui-forms-dialogs.md 6章。
- ルートエラー境界: 予期しない例外時、白画面ではなく「エラーが発生しました」+
  〔再読み込み〕+〔JSONエクスポート（メモリ上のデータの退避）〕を表示（ADR 0001）。

## 10. 配線網羅表は「該当なし」

本設計は新規開発（既存コードへの差分設計ではない）ため、配線網羅表は該当なし。
