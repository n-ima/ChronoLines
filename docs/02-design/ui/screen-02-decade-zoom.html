切り替え時は、切替前の表示中心の年が切替後も中心に来るようスクロール位置を再計算します（US-007）
10年セルの表示規則: 数値 = その10年の開始年時点の年齢（10年の途中で生まれた場合は 0）。 生存の帯 仮想年齢（括弧書き） セル左端の縦線 = この10年に生年、右端の縦線 = この10年に没年。 イベントは10年単位の件数バッジ（クリックで年別の全件をサイドパネルに表示）。
