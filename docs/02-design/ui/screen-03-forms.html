⚠ 保存データを読み込めませんでした

技術的な詳細JSON parse error: Unexpected end of input (position 182034)

次のいずれかで復旧できます:

  1. JSONファイルから復旧 — エクスポート済みのバックアップを取り込みます（下のボタン）
  2. 自動バックアップから手動復旧 — chronolines.json.bak を chronolines.json に上書きコピーし、サーバーを再起動してから「再試行」
  3. 空のデータで開始 — 読めなかったファイルは chronolines.corrupt-日時.json として保全されます
