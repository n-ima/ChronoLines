# 用語集

| 用語 | 定義 | 備考 |
|---|---|---|
| 年表（タイムライン） | 人物とイベントの集合を持つ、このアプリの管理単位。複数作成でき、切り替えて使う（例: 「戦国」「幕末」） | US-009 |
| 人物 | 年表の行になる登録対象。名前・生年（必須）・没年（任意）・タグを持つ。歴史上の人物に限らず誰でも登録できる | US-001 |
| イベント | 年に紐づく出来事。名前・年（必須）、月日・メモ・人物への紐付け（任意）を持つ | US-003 |
| 個人イベント | 特定の人物に紐付けられたイベント（例: 「◯◯の結婚」）。人物に紐付かないイベント（世の中の出来事）と区別する | US-003 |
| 満年齢 | セルに表示する年齢。「その年の誕生日で達する満年齢」とし、月日は使わず年単位で計算する。<br>・生年も表示年も西暦: `表示年 − 生年`<br>・生年が紀元前（前B）・表示年が西暦Y: `Y + B − 1`（紀元0年は存在しない）<br>・両方とも紀元前（生年 前B・表示年 前C）: `B − C`<br>・生年が西暦・表示年が紀元前: 常に生前のため空欄（US-002）<br>年の全順序: 前N同士はNが大きいほど過去。紀元前の年はすべて西暦の年より過去<br>例: 前100年生まれ → 前50年のセルは 50、西暦1年のセルは 100 | US-002 / US-005 |
| 仮想年齢 | 没後の年、および存命人物の現在年より後の年のセルに表示する「その年に生きていれば何歳か」。計算式は満年齢と同じで、色で生存中と区別する | US-002 |
| 現在年 | 実行時のシステム日付（PCの日付）の年。表示範囲の自動決定の既定の終端（US-006）、および存命人物の満年齢/仮想年齢の境界（US-002）に使う | US-002 / US-006 |
| 生存期間 | 生年から没年まで（存命なら現在まで）の期間。年表上で帯のように見える | US-002 / US-007 |
| 年のみ登録 | 生年・没年を月日なし（年だけ）で登録すること。年齢計算は年単位のため精度は変わらない | US-001 / A-005 |
| 紀元前表記 | 紀元前の年の表示形式「前500」。紀元0年は存在せず、前1年の翌年は西暦1年 | US-005 |
| タグ | 人物に付与する分類ラベル（例: 「戦国」「幕末」）。1人に0個以上。表示の絞り込みに使う | US-008 |
| グループ | タグと同義。本アプリの人物絞り込みはタグで実現する（タグとは別のグルーピング機能は作らない） | US-008 |
| ズーム | 年表の列単位を1年 ⇔ 10年で切り替える機能 | US-007 |
| スキーマバージョン | 保存データに記録する形式バージョン。アプリ更新時のデータ自動移行（後方互換）の判定に使う | US-010 |
| エクスポート / インポート | データ一式をJSONファイルとして出力/取り込みする機能。バックアップ・復旧の手段 | US-011 |
